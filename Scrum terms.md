Retrospectives  
Retro's will be standardly held on the Friday at the start of the hackathon lessons. If on Friday we are missing one or more people for the retro, we will skip Friday and do it on the first upcoming day. If on this day there is still a missing person, this person will not attend this retro, and there will be a short summary written during the retrospective for this person to catch up on the retrospective. The person that will write these documents is Mees van Aalten.

Standups:  
Standups will be held at the start of every lesson where we work on the hackathon if there are at least 2 people of the group present. There will be no document written for these standups, and this will be purely verbal communication about how people are progressing with their tickets, who needs help, and what their priority is. If there is only one person of the group in attendance, a standup will be skipped. Standups are also skippable if a person dictates that their time is more useful in the task that they are currently doing, but this should not be the norm.

Reviews:  
Reviews will be set to merge into development. A pull request will only be allowed to merge by someone else other than the primary contributor of the pull request into the development branch, as this dictates a stricter set of code quality.
